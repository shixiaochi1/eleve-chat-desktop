## 三、差距清单与施工任务

### P1-1 项目排序（纯前端）
**Hermes**：`sortProjectsForOverview` —— 激活项目置顶（仅显式）→ 显式先于自动 → 有会话先于无会话 → 最近活跃 → 名称（不区分大小写）；Home（isNoProject）恒首。
**ELEVE 现状**：后端仅 last_active 降序；激活项目不置顶。
**施工**：移植 `sortProjectsForOverview` 到 `ProjectTreePanel`（数据已在 tree.projects：isAuto/color/icon/sessionCount/lastActive/active_id 全字段齐），前端排序后渲染。后端不动。

### P1-2 「在该项目新建会话」（前端 + 后端一行）
**Hermes**：项目行 hover `+`（WorkspaceAddButton）→ `goToProject(id, {newSession:true})` → 新会话 draft 锚定项目根路径。
**ELEVE 现状**：无。会话 cwd 解析链已存在（`resolve_session_cwd`：env registry → DB 烙印 → profile terminal.cwd → TERMINAL_CWD → 进程 cwd；`update_session_cwd(sid, cwd)` 写 DB 烙印）。
**施工**：
- 后端 `rpc_session.rs handle_session_create`：raw_cwd 非空时创建后 `update_session_cwd(&short_sid, &raw_cwd)`（复用权威机制，不造轮子；当前 raw_cwd 只回显 info.cwd 未落库 = 断线）
- 前端项目行 hover `+` → `sessionCreate({profile, cwd: project.path})` → 切到新会话（sess.setSessionId + getWsClient().switchSession + persistSessionPointer + refresh + 清消息），复用 useSessionActions/handleSwitchSession 既有工具链。

### P1-3 项目菜单补全（纯前端）
**Hermes** `ProjectMenu`/`ProjectContextMenu` 共享 `useProjectActions`：
- 显式：rename / add-folder / set-active（ELEVE 已有）
- **reveal**（tauri-opener `revealItemInDir`，文件面板已装同款）
- **copy path**（clipboard）
- 自动项目：**「从侧边栏移除」dismiss**（Hermes 纯前端 persistentAtom 隐藏；ELEVE 自动项目来自 disk scan，同款 localStorage 隐藏）
- 显式项目：**「删除…」确认对话框**（Hermes deleteProject 删 projects.db 记录，不删文件；ELEVE 现有归档 archive 保留，补删除语义 —— 后端 `projects.delete` RPC 已存在，前端未用）
**施工**：菜单补 reveal/copy path/dismiss（自动项目）/删除确认（显式项目）；自动项目菜单只显示 appearance + dismiss（对齐 Hermes isAuto 分支）。

### P1-4 外观选择器：颜色 + 图标（纯前端，后端已支持）
**Hermes** `ProjectAppearancePicker`：颜色 swatches（可清除）+ 28 图标网格；自动项目首次改外观 = **adopt 收养**（createProject 携带外观，node id 变化，picker 关闭防双写）。
**ELEVE 现状**：仅颜色（AGENT_PALETTE 22 色），无图标；后端 projects.create/update 已支持 icon 字段。
**施工**：
- `PROJECT_ICONS` 28 个 codicon 名 → ELEVE lucide 图标映射表（新文件 `lib/project-icons.ts`）
- ProjectDialog 加图标选择；菜单「外观」popover/submenu 同款 picker
- adopt 语义：自动项目改外观 → `projects_create`（name=label, folders=[path], primary=path, 携带颜色+图标）→ 关闭 picker

### P1-5 项目行右键菜单（纯前端）
**Hermes** `ProjectContextMenu`：右键 = kebab 同款 action，Appearance 以 submenu 呈现。
**施工**：ELEVE 已有 ContextMenu 组件（文件面板在用），项目行包右键菜单，外观放子菜单。

### P1-6 文件面板内联重命名防抖（纯前端）
**Hermes** `InlineRenameInput`：`done` ref latch（Enter 后 blur 不二次提交）+ `mountedAt` 250ms 防抖（菜单关闭焦点回流不误提交）+ stem 预选。
**ELEVE 现状**：stem 预选有；无 latch/防抖 —— Enter 提交后若 blur 补发会二次 rename（旧路径+新名 → 报错）；菜单关闭 focus 回流有 onCloseAutoFocus preventDefault 兜底但仍缺 250ms 窗口。
**施工**：FileRow rename input 加 done latch + mountedAt 250ms 防抖。
