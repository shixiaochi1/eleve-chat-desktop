## 〇、北极星（老大 2026-07-30 确立）

每个 Agent 完全独立，互不影响。宫格模式 = 同时显示多个 Agent 的**全功能**聊天窗口（和单视图一样的功能，不是监视面板）。N 个 Agent 无上限（滚动网格），性能优先（ELEVE 常驻内存）。

**消息处理 = 聊天软件标准**：窗口化（最近 N 条）+ 上翻加载更早（before_id 游标）+ 不全量缓存 + 内存 evict。

## 四、架构铁律（必须遵守）

1. **后端是消息唯一权威源**，前端是视图。切走不存消息，切回/加载始终走后端。
2. **Agent 间零共享可变状态**。每个操作自带身份（session_id / params.profile），后端永不从全局猜。
3. **内存可控**（常驻安全）：每 Agent 窗口 100 条 evict，流式 buffer 完成即清。
4. **流式性能**：delta 只写 ref 累加器，30fps flush，不动消息列表（不触发列表重渲染）。
5. **宫格/单视图互斥**：useGridChat 和 useSSE 不并行，模式切换时交接。
6. **无上限设计**：状态层 `Record<profile, State>` 不硬编码数量，渲染层滚动网格。
