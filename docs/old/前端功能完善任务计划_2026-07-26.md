## 一、施工原则

1. **先修 bug 后加功能**：F0 是已确认的连接层 bug，直接影响用户体验，最先做。
2. **后端就绪 = 安全区**：F1-F4 全部是后端已有真实实现的端点，纯前端接线，与小哪吒零冲突。
3. **空壳激活优先于新建面板**：已有 UI 组件（UsagePanel/DebugPanel/FileBrowserPanel）接真实数据，比从零造面板成本低、回归面小。
4. **优雅降级不造假**：后端是 stub 的功能（voice/archive/pet 生成），前端明确提示"功能开发中"，绝不返回假状态骗用户。
5. **每阶段可独立交付**：每个 Phase 结束都是可打包、可测试的完整状态，不留半成品。
